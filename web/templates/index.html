get started

Deploy a repository to get your first site online. Public repositories need no access token.

deploy a repository

  1. Enter a GitHub, GitLab, or Codeberg repository and choose the branch to deploy.

  2. Choose the publish directory containing your committed HTML, CSS, and JavaScript files. Leave it blank to serve the repository root.

  3. Open your site from the project page once deployment finishes. You can set up automatic deployments for GitHub afterward.
